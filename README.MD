# Minecraft ReAct-agent

ReAct-агент для сервера Minecraft 1.12.2, который общается с игроками в чате и помогает 
управлять ресурсами: отслеживает инвентарь, сканирует сундуки, запоминает координаты 
и отвечает на вопросы, опираясь на реальное состояние игрового мира.

## Описание

Агент читает лог-файл сервера в реальном времени, определяет сообщения игроков в чате 
и формирует ответ с помощью LLM. Перед каждым ответом агент собирает контекст о мире 
(здоровье игрока, координаты, инвентарь, время суток) и может вызывать инструменты 
для получения дополнительной информации.

**Доступные инструменты агента:**
- `check_inventory` - проверка инвентаря игрока
- `inspect_looked_at_container` - сканирование сундука, на который смотрит игрок (через raycast)
- `inspect_container_at_coords` - сканирование контейнера по координатам
- `check_global_storage` - суммарный подсчёт ресурсов по всем известным сундукам
- `save_to_memory` / `read_memory` — сохранение и чтение произвольной информации (координаты баз, планы и т.д.)

## Технологии

- Python
- LangGraph - построение ReAct-цикла агента
- LangChain (ChatOpenAI) - взаимодействие с LLM
- RCON (mcrcon) - отправка команд на Minecraft-сервер
- NBT - чтение файлов данных игрока (`playerdata`)

## Установка

```bash
git clone https://github.com/gmdEGXYZ/mc-react-agent.git
cd mc-react-agent
pip install -r requirements.txt
```

## Настройка

1. Скопируйте `.env.example` в `.env`:
```bash
cp .env.example .env
```
2. Заполните переменные в `.env`:
   - `LLM_API_KEY`, `LLM_URL`, `LLM_MODEL` — доступ к LLM
   - `RCON_PASSWORD`, `RCON_HOST`, `RCON_PORT` — доступ к серверу Minecraft по RCON

3. Включите RCON на сервере Minecraft в `server.properties`:
```
enable-rcon=true
rcon.port=25575
rcon.password=ваш_пароль
```

## Запуск

```bash
python main.py
```

Агент начнёт слушать лог-файл сервера и отвечать на сообщения игроков в чате.

## Ограничения

- Чтение данных игрока (инвентарь, координаты, зачарования) реализовано через парсинг `.dat`-файлов 
  в папке `playerdata`, что требует доступа к файловой системе сервера.
- Проверено на сервере Vanilla/Paper, версия Minecraft 1.12.2.
